🚀 We're building Codragraph — the context layer for agentic AI.

Here's what we noticed:

Every AI agent today reads 30,000 tokens to answer a question that needed 4,000.

Cursor pulls 12 files via grep. Copilot scrolls your buffer. Claude Code grep-loops until it finds something. The model wades through slop.

The bill silently compounds. Smaller models can't compete because they're fed the same noisy context as flagship models. Teams default to Opus and GPT-5 everywhere — and the per-engineer monthly inference bill quietly hits $400.

Codragraph is the layer between your codebase and your agent.

Four parts, each one multiplies the next:

🧭 Code-aware retrieval. Your repo as a graph (16 languages, 45 node types, 23 relationship types), with FeatureCluster packs for product areas like Settings/Auth/AI. The agent gets the right files, not the substring matches.

🗜️ LLM-aware compression. Bound the worst case when retrieval misses.

🤖 Auto-tuned harness. The agent learns the optimal recipe for each task family. Pareto frontier on accuracy / tokens / latency.

📜 Versioned graph (the moat). Each commit produces a content-addressed snapshot. The harness's winning recipes get tagged against your code's structural fingerprint. Reuse across thousands of runs. Auto-invalidate only when the relevant code actually changes.

Result: 60–85% token reduction on typical agent workflows. Smaller models like Claude Haiku and GPT-5.5-mini producing flagship-quality outputs. At a fraction of the cost.

Local-first. BYO API key. Works with Claude Code, Codex, OpenCode, Cursor, Aider, or any inference provider via the SDK.

Open source under Apache-2.0. Available soon on npm.

If you're building agentic AI and tired of paying for context your model didn't even read — let's talk.
