# CodraGraph v2.1.6

CodraGraph v2.1.6 focuses on making day-to-day indexing faster and making
agent-facing change detection reliable.

## Highlights

- `codragraph analyze` now patches changed file-scoped graph rows for source
  edits, renames, large diffs, and topology-only files instead of falling back
  to the old full database reload path.
- Package/config/ignore input changes refresh all file-scoped rows while still
  preserving the existing database and metadata flow.
- After every graph mutation, CodraGraph recomputes communities, execution
  flows, and FeatureCluster packs so global context stays current.
- `detect-changes --scope unstaged` and `detect-changes --scope all` now return
  normal CLI output instead of silently exiting on LadybugDB native
  label/projection edge cases.
- Workspace packages, integrations, and web package are aligned at `2.1.6`.

## Upgrade

```bash
npm install -g @codragraph/cli@2.1.6
codragraph analyze .
```

With Bun:

```bash
bun add -g @codragraph/cli@2.1.6 --trust
codragraph analyze .
```

## Notes

- BM25 and graph retrieval still work without embeddings.
- Use `codragraph analyze --embeddings` only when vectors are needed or must be
  preserved from an existing index.
- Use `codragraph detect-changes --scope all` before commit when you want both
  staged and unstaged changes in one impact report.
