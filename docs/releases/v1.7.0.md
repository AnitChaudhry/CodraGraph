## Highlights

**One-command zero install.** `npx @codragraph/cli analyze` now does
everything: detects first-run, configures Claude / Cursor / Codex / OpenCode
MCP, installs hooks, and indexes your repo. No more 3-step setup. Opt out
of auto-setup with `--no-setup` for CI.

**Token savings, finally visible.** Every `query`, `context`, `impact`, and
`analyze` summary ends with `@codragraph/compress: ~N tokens of structured
context (vs ~M raw — P% smaller).` The number is computed from the actual
on-disk file sizes the response references — no more abstract claims.

**PR structural-diff GitHub Action.** Drop a workflow file and every PR
gets a sticky comment listing removed APIs, added APIs, modified
signatures, added/removed execution flows, and a heuristic risk level.
`mode: deterministic` is free; `mode: review` adds an Anthropic-driven
human-readable review on top.

**Background auto-reindex on commit.** Set `CODRAGRAPH_AUTO_REINDEX=1` or
`~/.codragraph/config.json#autoReindex` and the Claude Code PostToolUse
hook reindexes in the background after every `git commit` / `merge` /
`rebase` / `pull`. Coalesce-file gating handles amend/rebase storms.

**32 built-in workflow skills.** Up from 17. New coverage spans dev
power-tools (test-coverage, dead-code, api-surface, onboarding,
migration-tracking), data engineering (data-lineage, sql-tracing,
notebook-context), multi-project / vibecoding (project-switcher,
cross-repo-impact), git workflow (rebase-vs-merge, force-push, recovery,
bisect, worktree, history-rewrite), GitHub CLI (pr/issue/actions/release),
and domain audits (security, perf, observability, config, supply-chain).
All auto-installed to `.claude/skills/`, `.cursor/skills/`,
`.opencode/skill/`, and `.agents/skills/` by `codragraph setup`.

## What's in the box

### CLI

- `analyze --no-setup` — opt out of first-run setup.
- `analyze --skill-targets <list>` — emit `--skills` to multiple editors.
- `diff --json` — machine-readable shape for both `--semantic` and plain.
- Token-savings line on every tool result.

### Hooks

- Background auto-reindex with config.json fallback (Windows-safe).
- `.codragraph/.reindex.coalesce` gate with cleanup-on-exit.

### CI

- `.github/actions/codragraph-pr-review/` composite Action.
- Sample workflow gated by `if: false` until you flip it on.

### Skills

22 new flat-`.md` skills under `packages/core/skills/`. See
[the README's skills table](https://github.com/AnitChaudhry/CodraGraph#built-in-skills)
for the full list with trigger phrases.

## Upgrade

```sh
npm i -g @codragraph/cli@1.7.0
```

No breaking changes. The 17 existing skills are untouched; the 15 new
ones land in your editor skill directories on next `codragraph setup`.

## Compatibility

- Existing 1.6.x indexes work unchanged.
- The PR review GitHub Action requires this version — earlier CLIs lack
  `analyze --no-setup`, `diff --json`, and the graphstore `headCommit`
  write the action depends on. The example workflow ships gated to keep
  consumers on older CLIs from accidentally enabling it.
