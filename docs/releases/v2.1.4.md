# CodraGraph v2.1.4

CodraGraph v2.1.4 focuses on making release artifacts and day-to-day indexing
more reliable for AI-agent workflows.

## Highlights

- Smart `analyze` reuse: non-index-impacting commits can advance metadata
  without rebuilding the LadybugDB graph.
- Public repo export now generates version-accurate README, install snippets,
  package tables, tarballs, and checksums from workspace package manifests.
- Public repo contents include end-to-end docs, package README mirrors,
  branding, issue templates, and downloadable npm packages.
- Workspace packages, integrations, and web package are aligned at `2.1.4`.

## Upgrade

```bash
npm install -g @codragraph/cli@2.1.4
codragraph analyze .
```

With Bun:

```bash
bun add -g @codragraph/cli@2.1.4 --trust
codragraph analyze .
```

## Notes

- `analyze --force` still performs a full rebuild.
- Source, Markdown/docs, config, file-structure, schema, compression, and
  requested embedding changes still rebuild conservatively.
- Generated agent context, lockfile-only changes, and ignored assets can reuse
  the existing graph.
