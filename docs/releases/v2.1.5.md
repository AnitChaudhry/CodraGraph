# CodraGraph v2.1.5

CodraGraph v2.1.5 focuses on making CLI commands, hooks, and analyzer output
safer for AI agents on Windows/macOS/Linux.

## Highlights

- Direct graph CLI commands now use the indexed repo under the current working
  directory and fail clearly when the cwd is not indexed.
- `analyze` refreshes `.codragraph/structure/`, a compact agent memory pack
  with what/why/how/when/where docs, branch/index state, bounded history,
  `state.json`, and SQLite seed SQL.
- Analyzer worker parsing now uses smaller sub-batches and progress-reset idle
  timeouts, including worker flush/finalize waits.
- Claude and Codex hooks are read-only in the hot path: no background analyze,
  no `detect-changes`, and no package-runner install/fetch.
- Workspace packages, integrations, and web package are aligned at `2.1.5`.

## Upgrade

```bash
npm install -g @codragraph/cli@2.1.5
codragraph analyze .
```

With Bun:

```bash
bun add -g @codragraph/cli@2.1.5 --trust
codragraph analyze .
```

## Notes

- BM25 and graph retrieval still work without embeddings.
- `.codragraph/structure/` is ignored by the indexer so generated agent memory
  does not cause rebuild loops.
- If a direct graph command says the current repository is not indexed, run
  `codragraph analyze` from that repo or pass an explicit `--repo`.
